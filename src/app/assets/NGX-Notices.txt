NVIDIA NGX runtimes
===================

nvngx_dlss.dll is NVIDIA's DLSS Super Resolution runtime and
nvngx_dlssg.dll is its DLSS Frame Generation runtime, both distributed in
object form under the NVIDIA RTX SDKs License (licenses/NGX-License.txt).

This software contains source code provided by NVIDIA Corporation.

The runtime includes third-party components acknowledged by the DLSS SDK:
curl (Daniel Stenberg and contributors), the 8x13 SGI bitmap font, and
Microsoft's d3dx12.h.
